# HR HydroCalc

Статичен уебсайт с хидравлични калкулатори на български. Сайтът няма сървърна част и работи с HTML, CSS и JavaScript.

## Преглед локално

Отвори `index.html` в актуален браузър. За публикуване качи цялата папка така, че `index.html` да бъде началната страница. Не отделяй `retention-tank.html`, защото калкулаторът за задържателен резервоар се зарежда от него.

## Публикуване

Папката е подготвена за статичен уеб хостинг. При услуга, която публикува от Git хранилище, свържи хранилището и посочи `outputs/hydraulic-calculators` като директория за публикуване; не е необходима команда за компилиране. При услуга с качване на статични файлове качи съдържанието на тази папка.

За собствен домейн ще трябва да свържеш домейна в настройките на избрания хостинг и да добавиш DNS записите, които доставчикът посочи.

## Файлове

- `index.html` — страницата и калкулаторите.
- `app.js` — изчисленията и управлението на екраните.
- `styles.css` — оформление за desktop и мобилни устройства.
- `retention-tank.html` — оригиналният вграден калкулатор.
- `favicon.svg`, `site.webmanifest`, `robots.txt` — икона и базови метаданни за уебсайт.

## Забележка

Резултатите са ориентировъчни и трябва да се проверяват спрямо проекта, приложимите нормативни изисквания и условията на обекта.
